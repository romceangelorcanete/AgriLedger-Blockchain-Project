# 🌱 AgriLedger
### Blockchain-Based Vegetable Supply Chain Monitoring System

AgriLedger is a blockchain-powered vegetable supply chain monitoring system designed to improve transparency, security, and traceability in agricultural product movement. The system uses blockchain technology and smart contracts to create tamper-proof records from farmers to vendors.

---

## 📖 Overview

Traditional agricultural supply chains often rely on manual record keeping, making it difficult to verify product information and monitor transactions. AgriLedger addresses these issues by providing a secure and transparent digital platform that tracks vegetables throughout the supply chain.

The system ensures that every transaction is permanently recorded and cannot be modified, helping improve trust among stakeholders.

---

## 🎯 Objectives

- Develop a blockchain-based vegetable supply chain monitoring system
- Improve transparency in agricultural product movement
- Provide secure and tamper-proof transaction records
- Monitor shipment and delivery of vegetable products
- Implement QR code verification for product tracking
- Improve trust among farmers, traders, transporters, and vendors
- Reduce manual errors in agricultural record management

---

## 👥 User Roles

### 🌾 Farmer
- Registers vegetable products
- Supplies agricultural products
- Updates product information

### 🛒 Trader
- Purchases agricultural products
- Distributes products

### 🚚 Transporter
- Handles shipment logging
- Updates delivery status

### 🏪 Vendor
- Receives delivered products
- Confirms delivery

### ⚙️ Admin
- Manages users
- Verifies transactions
- Monitors system activities

---

## 🔗 Supply Chain Flow

Farmer → Trader → Transporter → Vendor

1. Farmer registers vegetable products
2. Trader purchases and distributes products
3. Transporter records shipment details
4. Vendor confirms product delivery
5. QR code can be scanned for product verification
